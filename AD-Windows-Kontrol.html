Active Directory — Windows'tan Kontrol

Kali'nin karşılığı: bir Windows makinesinden AD keşfi, güvenlik denetimi ve saldırı yolu analizi nasıl yapılır? Yerleşik araçlardan (kurulum yok) PowerView / SharpHound / PingCastle'a kadar adım adım, komutlarla.

Örnek Domain: corp.local Örnek Kullanıcı: claire Örnek DC: DC01 / 192.168.11.10

Windows'tan bakış: iki ayrı senaryo

Kali'de "dışarıdan ağa bağlı bir saldırgansın". Windows'ta ise genelde zaten domain'in içindesin — bu büyük bir avantaj: makine seni Kerberos ile authenticate ettiği için, LDAP'ı hiçbir parola girmeden sorgulayabilirsin. Hangi araçları kullanacağın, aşağıdaki iki durumdan hangisinde olduğuna bağlı.

Mod A

Domain'e üye makine + normal kullanıcı

En yaygın lab senaryosu. Windows'un kendi araçlarıyla (ADSI, net, nltest, setspn, dsquery) hiçbir şey kurmadan keşif yaparsın.

Mod B

RSAT / PowerView / araç kurulabilir

Denetim (audit) veya derin keşif. ActiveDirectory modülü, PowerView, SharpHound→BloodHound, PingCastle ile ACL / delegation / saldırı yolu analizi.

Ortamı anla→ Kullanıcı & grup→ Bilgisayar & DC→ Zayıf ayar (SPN/PreAuth/Delegation)→ ACL & yol→ Denetim raporu
Bu rehber yalnızca yazılı izin aldığın kendi lab / pentest ortamın içindir. Buradaki komutların çoğu pasif LDAP sorgusudur (non-destructive). PowerView'in Invoke-*, password-spray ve Rubeus gibi aktif adımlar account-lockout / iz bırakma riski taşır — lab dışı kullanma.

01

Ortamı Anla — Domain & DC Tespiti

Pasif
Hangi domain'deyim, DC kim, DNS/site yapısı ne? Hiçbir araç kurmadan sadece cmd/PowerShell.

🔧 cmd / env — anlık durum

:: Hangi domain, hangi DC beni authenticate etti?
echo %USERDOMAIN%      :: NETBIOS domain
echo %USERDNSDOMAIN%   :: FQDN (corp.local)
echo %LOGONSERVER%     :: beni logon eden DC (\\DC01)
whoami /fqdn
whoami /groups         :: üye olduğum gruplar + SID'ler
whoami /priv           :: token üzerindeki ayrıcalıklar

🔧 nltest — DC / trust keşfi

:: Domain'in DC'lerini bul
nltest /dclist:corp.local
nltest /dsgetdc:corp.local        :: en yakın DC + adres + site
nltest /domain_trusts /all_trusts :: domain/forest trust ilişkileri

🔧 nslookup — DNS ile DC/servis kaydı

:: Kerberos & LDAP SRV kayıtları = DC listesi
nslookup -type=SRV _ldap._tcp.dc._msdcs.corp.local
nslookup -type=SRV _kerberos._tcp.corp.local
%LOGONSERVER% sana anında bir DC verir. Onun IP'sini nslookup DC01.corp.local ile çöz, sonraki tüm sorgularda hedef olarak kullan.
02

Yerleşik Araçlarla Keşif

Pasif
Kurulum gerektirmeden kullanıcı, grup, bilgisayar ve SPN listesini çıkar. Her Windows'ta hazır gelen komutlar.

🔧 net — hızlı kullanıcı/grup

net user /domain                      :: tüm domain kullanıcıları
net user claire /domain               :: tek kullanıcı detay (grup, son parola)
net group /domain                     :: tüm domain grupları
net group "Domain Admins" /domain     :: DA üyeleri — en kritik hedef
net group "Enterprise Admins" /domain
net accounts /domain                  :: parola politikası & lockout eşiği
net accounts /domain ile lockout eşiğini öğren. Eşik 3-5 ise password-spray denemeden önce iki kez düşün — hesapları kilitlersin.

🔧 dsquery — LDAP sorgusu (varsa)

dsquery user -limit 0                 :: tüm kullanıcıların DN'i
dsquery computer -limit 0             :: tüm bilgisayarlar
dsquery * -filter "(&(objectCategory=user)(servicePrincipalName=*))" -attr samAccountName servicePrincipalName

🔧 setspn — Kerberoast adayları

setspn -T corp.local -Q */*           :: domaindeki tüm SPN'ler
setspn -L DC01                        :: bir hesabın SPN'leri
Not: dsquery ve setspn, RSAT / AD-DS rol araçlarıyla gelir; DC'de veya RSAT kurulu makinede hazırdır. Yoksa Mod A'da bir sonraki adımdaki ADSI yöntemini kullan — o her yerde çalışır.
03

ADSI / PowerShell — Kurulum YOK

Pasif
Hiçbir modül/araç olmadan, saf .NET ile LDAP sorgusu. Domain'e üye her Windows'ta çalışır — en taşınabilir yöntem.

🔧 [adsisearcher] — tek satırlık LDAP

# Tüm kullanıcılar
([adsisearcher]"(&(objectCategory=user))").FindAll() |
  % { $_.Properties.samaccountname }

# Tüm bilgisayarlar + işletim sistemi (eski OS = zayıf halka)
$s = [adsisearcher]"(objectCategory=computer)"
$s.PropertiesToLoad.AddRange(@("name","operatingsystem"))
$s.FindAll() | % { "{0,-18} {1}" -f $_.Properties.name, $_.Properties.operatingsystem }

# Domain Admins üyeleri
([adsisearcher]"(&(objectCategory=group)(cn=Domain Admins))").FindOne().Properties.member

🔧 Zayıf ayar filtreleri — bit-mask ile

# Kerberoastable — SPN'i olan kullanıcı hesapları
([adsisearcher]"(&(objectCategory=user)(servicePrincipalName=*))").FindAll() |
  % { $_.Properties.samaccountname }

# AS-REP roastable — Kerberos pre-auth KAPALI (UAC bit 4194304)
([adsisearcher]"(&(objectCategory=user)(userAccountControl:1.2.840.113556.1.4.803:=4194304))").FindAll() |
  % { $_.Properties.samaccountname }

# Parola asla eskimeyen hesaplar (UAC bit 65536)
([adsisearcher]"(&(objectCategory=user)(userAccountControl:1.2.840.113556.1.4.803:=65536))").FindAll() |
  % { $_.Properties.samaccountname }

# Unconstrained delegation'lı bilgisayarlar (UAC bit 524288) — çok kritik
([adsisearcher]"(&(objectCategory=computer)(userAccountControl:1.2.840.113556.1.4.803:=524288))").FindAll() |
  % { $_.Properties.name }
Bu dört sorgu tek başına bir mini "güvenlik denetimi"dir. Çıktı boş dönmesi iyi; dolu dönen her satır bir bulgu adayıdır.
04

RSAT — ActiveDirectory Modülü

Kurulum
Microsoft'un resmi denetim aracı. En temiz, en "meşru görünen" keşif — Get-AD* cmdlet'leri.

🔧 Kurulum (yönetici PowerShell)

# Windows 10/11 istemci
Add-WindowsCapability -Online -Name Rsat.ActiveDirectory.DS-LDS.Tools~~~~0.0.1.0
# Windows Server
Install-WindowsFeature RSAT-AD-PowerShell
Import-Module ActiveDirectory

🔧 Get-AD* — çekirdek keşif

Get-ADDomain                          # domain SID, mode, DC, FSMO
Get-ADForest
Get-ADDomainController -Filter *

# Kullanıcılar + kritik alanlar
Get-ADUser -Filter * -Properties LastLogonDate,PasswordLastSet,Enabled |
  select SamAccountName,Enabled,LastLogonDate,PasswordLastSet | ft -Auto

# Ayrıcalıklı grup üyeleri (recursive)
Get-ADGroupMember "Domain Admins" -Recursive | select name,SamAccountName
Get-ADGroupMember "Enterprise Admins" -Recursive

# Parola politikası
Get-ADDefaultDomainPasswordPolicy
Get-ADFineGrainedPasswordPolicy -Filter *

🔧 Zayıf ayar sorguları

Get-ADUser -Filter {ServicePrincipalName -like "*"} -Properties ServicePrincipalName   # Kerberoast
Get-ADUser -Filter {DoesNotRequirePreAuth -eq $true}                                    # AS-REP
Get-ADUser -Filter {PasswordNeverExpires -eq $true}
Get-ADComputer -Filter {TrustedForDelegation -eq $true} -Properties TrustedForDelegation # unconstrained
# Constrained delegation
Get-ADObject -Filter {msDS-AllowedToDelegateTo -like "*"} -Properties msDS-AllowedToDelegateTo
05

PowerView — Derin Keşif

Yarı-aktif
RSAT'ın göremediği şeyleri gör: ACL'ler, GPO, oturum açan kullanıcılar, güven ilişkileri, delegation. Pentest'in Windows'taki İsviçre çakısı.

🔧 Yükleme

# PowerSploit / PowerView (lab: bloke edilirse AMSI/ExecutionPolicy)
powershell -ep bypass
Import-Module .\PowerView.ps1
# veya: IEX (Get-Content .\PowerView.ps1 -Raw)

🔧 Domain / kullanıcı / bilgisayar

Get-Domain ; Get-DomainController ; Get-DomainPolicy
Get-DomainUser -Properties samaccountname,description,memberof
Get-DomainUser -SPN               # Kerberoast adayları
Get-DomainUser -PreauthNotRequired # AS-REP adayları
Get-DomainComputer -Unconstrained  # unconstrained delegation
Get-DomainComputer -TrustedToAuth  # constrained delegation

🔧 ACL & saldırı yolu — asıl değer burada

# "Kim kimin üzerinde tehlikeli hak sahibi?" (GenericAll, WriteDacl, ...)
Find-InterestingDomainAcl -ResolveGUIDs |
  ? { $_.IdentityReferenceName -notmatch 'Domain Admins|Enterprise' } |
  select IdentityReferenceName,ActiveDirectoryRights,ObjectDN

# Belirli bir kullanıcının domaindeki tüm hakları
Get-DomainObjectAcl -Identity "Domain Admins" -ResolveGUIDs

🔧 Oturum / erişim avı

Find-DomainUserLocation            # DA hangi makinede oturum açmış?
Find-LocalAdminAccess              # benim local admin olduğum makineler
Invoke-ShareFinder -CheckShareAccess
Find-DomainUserLocation, Invoke-ShareFinder gibi komutlar ağdaki onlarca makineye bağlanır — gürültü yapar ve EDR tetikler. Lab'da serbest, ama gerçek işte scope/timing'e dikkat.
06

Zayıf Ayar Avı — Kontrol Listesi

Pasif
Bir denetimde "bulgu" olarak yazacağın klasik AD zayıflıkları ve Windows'tan tespit komutları.
  • Kerberoasting — servis hesabında SPN + zayıf parola → Get-DomainUser -SPN
  • AS-REP Roasting — pre-auth kapalı hesap → Get-DomainUser -PreauthNotRequired
  • Unconstrained Delegation — DC dışı makinede açıksa kritik → Get-DomainComputer -Unconstrained
  • PasswordNeverExpires / eski/boş parola → Get-ADUser -Filter {PasswordNeverExpires -eq $true}
  • LAPS yok — yerel admin parolası her yerde aynı → Get-ADComputer -Filter * -Properties ms-Mcs-AdmPwd (erişebiliyorsan sorun)
  • Tehlikeli ACL — normal kullanıcıda GenericAll/WriteDacl → Find-InterestingDomainAcl
  • SYSVOL cpassword (GPP) — eski Group Policy Preferences parolası:
# SYSVOL'de saklanmış (kırılabilir) GPP parolası ara
findstr /S /I cpassword \\corp.local\sysvol\corp.local\policies\*.xml
Her bulgu için üç şey not al: Kanıt (komut çıktısı), Risk (ne mümkün oluyor), Düzeltme. Repo'daki ad-pentest-rapor-sablonu.html tam bu formatta.
07

BloodHound / SharpHound

Yarı-aktif
Tüm domain'i grafik olarak topla; "buradan Domain Admin'e giden en kısa yol nedir?" sorusunu görselleştir.

🔧 SharpHound — toplama (Windows'tan)

# Exe ile
SharpHound.exe -c All --zipfilename corp_bh
# PowerShell portu ile
Import-Module .\SharpHound.ps1
Invoke-BloodHound -CollectionMethod All -OutputPrefix corp_bh
# Daha sessiz: sadece DC'den LDAP, oturum toplamayı azalt
SharpHound.exe -c DCOnly --zipfilename corp_dconly

🔧 BloodHound — analiz

  • Üretilen .zip'i BloodHound GUI'ye sürükle.
  • Hazır sorgular: Shortest Paths to Domain Admins, Find Principals with DCSync Rights, Kerberoastable Users.
  • Kendi kullanıcını "başlangıç" işaretle → "Shortest path to Domain Admins" ile yolunu gör.
DCOnly vs All: DCOnly sadece DC'ye LDAP atar, session/loggedon toplamaz → çok daha sessiz ama yol analizi zayıflar. Lab'da All, gerçek ortamda önce DCOnly mantıklı.
08

PingCastle — Denetim Raporu

Pasif
Saldırgan değil denetçi gözüyle: domain'in güvenlik skorunu ve somut zayıflıklarını tek HTML raporda çıkar. Yönetime sunmak için ideal.

🔧 PingCastle

# Etkileşimli menü
PingCastle.exe
# Doğrudan healthcheck (HTML + XML rapor üretir)
PingCastle.exe --healthcheck --server corp.local
# Sadece belirli DC
PingCastle.exe --healthcheck --server DC01.corp.local
  • Çıktı: ad_hc_corp.local.html — risk skoru (Stale Objects, Privileged Accounts, Trusts, Anomalies).
  • Her bulguda puan + açıklama + düzeltme hazır gelir; rapora doğrudan taşınır.
  • Tamamen LDAP okuma tabanlı → non-destructive, lockout riski yok.
Bir lab denetiminde sıralaman: PingCastle (genel skor) → BloodHound (somut yollar) → PowerView (tek tek doğrulama ve kanıt). Üçü birbirini tamamlar.
